# 😂 React Joke Generator Project

A simple and fun **React + Vite Joke Generator App** that fetches random jokes from an API and lets users reveal punchlines interactively. Built for practicing API handling, React hooks, and UI state management.
 
---

## 🚀 Features

* 😂 Fetch random jokes from API  
* 👀 Show / Hide punchline toggle  
* 🔄 Load new joke instantly  
* ⚡ Loading state handling  
* 🎯 Clean and responsive UI  

---

## 🛠️ Tech Stack

* React.js (useState, useEffect)  
* Vite (Fast build tool)  
* JavaScript (ES6+)  
* CSS3 (Custom styling)  
* Fetch API (Joke API integration)  

---

## 📌 Topics Used

* React Functional Components  
* useState Hook  
* useEffect Hook  
* Fetch API  
* Event Handling  
* Conditional Rendering  
* Component Structure

## ⚙️ How to Run This Project

### 1. Clone the repository
```
git clone https://github.com/your-username/react-joke-generator.git
```
### 2. Move to project folder
```
cd react-joke-generator
```

### 3. Install dependencies
```
npm install
```

### 4. Start development server
```
npm run dev
```

---

## 💡 Usage

- App automatically loads a joke  
- Click **Show Punchline** to reveal answer  
- Click **New Joke** to fetch another joke
